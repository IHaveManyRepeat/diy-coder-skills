## 1. 类型判定

一个对象是链接，当且仅当：**它把人带到别处**（换页 / 换锚点 / 换站点）。判据是**语义**，不是样式：

| 形态 | 语义 | 归类 |
| --- | --- | --- |
| 文字带下划线，点了换页 | 导航 | **链接**（本件） |
| 样式做成按钮、点了换页 | 导航 | **链接**（本件；源侧称 Link Button）——`<a>` 而非 `<button>` |
| 样式是文字，点了提交表单 | 动作 | **按钮**（`button.md`） |
| 点了在同一页展开/收起 | 页内状态变化 | 不是链接（按所属对象的交互项记） |

**判据一句话**：**能改 URL 的是链接，改状态的是按钮**。

## 3. 链接类型（五选一）

| 值 | 用途 | 判据 / 备注 |
| --- | --- | --- |
| **导航链接** | 去另一个页面 | 目标写页 ID；进导航结构（`reached_from` 的上游） |
| **锚点链接** | 同页跳段 | `href="#id"`；目标元素必须有 `id`；**滚动后焦点要跟着走**（键盘用户不被丢下） |
| **外部链接** | 出站 | 建议新标签页 + `rel="noopener noreferrer"`；**外部目标要在文案里明示**（不让人误以为还在站内） |
| **功能性链接** | 下载 / 邮件 / 电话（`mailto:` / `tel:`） | 写清触发的动作；移动端键盘类型 |
| **Link Button** | 样式是按钮、语义是导航 | 用 `<a>` 承载，**不要**用 `<button>` 再挂跳转脚本（语义错位会让键盘与读屏行为变怪） |

## 4. 状态清单（四态，逐态写「看得见的变化」）

| 态 | 必须写清 | 备注 |
| --- | --- | --- |
| **默认** | 色 / 装饰（下划线有无）/ 字重 / 图标 | 全走 token |
| **悬停** | 色 / 装饰变化 / 光标 | **必须至少一条非色彩信号**（下划线出现 / 图标位移）——否则 `check` 判 `color-only-signal` |
| **激活 / 已访问** | 是否区分已访问；激活时的即时反馈 | 已访问状态在多页站点里要一致 |
| **聚焦** | 焦点环 / 装饰 | 键盘可达的硬要求 |

## 5. 点击行为（按五问写全）

1. **点到什么**（整块可点还是只有文字可点——**外扩点击区要写清边界**）；
2. **去哪**（引页 ID / 锚点 / 外部 URL）；
3. **同标签还是新标签**（新标签必须说明「为什么新标签」——源侧口径：只有用户预期会回来的场景才开新标签）；
4. **失败/不可达时**（外链失效、目标页不存在）**看到什么**；
5. **是否可键盘激活**（Tab 可达、Enter 触发；**这是链接不是按钮，不要绑 Space**）。

## 6. 示例

```html
<!-- 站内导航链接：目标引页 ID；色走 token；悬停有非色彩信号 -->
<a class="nav-link" href="/orders">查看全部订单</a>

<!-- 外部链接：新标签页 + rel；文案里明示是站外 -->
<a href="https://example.com/changelog" target="_blank"
   rel="noopener noreferrer">在站外查看更新日志<span class="icon-external" aria-hidden="true">↗</span></a>

<!-- 锚点链接 -->
<a href="#pricing">跳到价格表</a>
```
