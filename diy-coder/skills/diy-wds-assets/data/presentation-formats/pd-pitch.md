# PD — 投资人路演

## Overview
以 **problem → solution → traction → ask** 四拍叙事弧为主干，数字要跳出来、气质要专业。

## Format Characteristics

| Property | Value |
|----------|-------|
| **Aspect** | 16:9（投屏）/ A4 横（带走材料） |
| **Frames** | 四拍骨架：问题 → 方案 → 进展（traction）→ 要什么（ask）；每拍 2–4 页 |
| **Density** | 一页一个论点 + 一个证据；数字单独占视觉重心 |
| **Type scale** | 关键数字 ≥ 正文字号的 3 倍（数字就是这一页的主角） |
| **Transition** | 每拍结尾给一个「所以呢」，把读者推进下一拍 |
| **Chart treatment** | 增长曲线 / 漏斗 / 单位经济三件套；坐标轴与单位必须标全（投资人会追问） |

## Prompt Recipe

```
Craft an investor pitch presentation. Build a narrative arc (problem → solution → traction → ask), design data visualizations that make the numbers pop, and enforce a polished, professional visual language.
```

> **输入来源**：`wds-brief.yaml` 的 `brief.core`（愿景 / 定位 / 业务模式 / 目标用户 / 成功标准 / 竞争格局）逐项对得上四拍——这是 diy 侧「演示跨域可容」的真正依据（census-4 §7-③）。

## Best For
- 融资路演 / 投资人一对一 / 加速器 Demo Day
- 需要「一页说清一个数字」的任何高层汇报

## Review Gate
- 叙事弧：四拍齐全且顺序不乱（traction 不能跑到 problem 前面）
- 数字跳出来：每页的数字在 3 秒内被看到
- 专业度：坐标轴 / 单位 / 口径标全，不留模糊表述
