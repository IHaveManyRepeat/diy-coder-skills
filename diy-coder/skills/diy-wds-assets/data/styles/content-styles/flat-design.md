# 扁平设计（Flat Design）

## 概述
无渐变、无阴影、无 3D 效果——纯粹的形状、干净的色彩、几何化的简洁。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 低——最大程度简化 |
| **光照** | 无——纯色平涂 |
| **质感** | 无——平滑均匀 |
| **色彩** | 纯色填充，限定色板 |
| **景深** | 无——纯 2D |

## Prompt Keywords
> **提示词**——英文行整段贴入外部生成服务；下行中文对照仅供理解。
`flat design, flat illustration, minimalist, geometric, solid colors, no shadows, 2D, clean shapes`
中文对照：扁平设计、扁平插画、极简、几何感、纯色平涂、无阴影、二维、干净形状

## 适用场景
- UI 元素、图标、信息图、新手引导插画
- 加载快速的素材、可缩放的图形
