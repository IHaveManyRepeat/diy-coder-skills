# 铅笔素描（Pencil Sketch）

## 概述
手绘铅笔或炭笔效果——质朴、真实，带有未完成的现场感。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 不定——从粗略到精细 |
| **光照** | 色调明暗、交叉排线 |
| **质感** | 纸张纹理、石墨涂抹痕迹 |
| **色彩** | 灰阶（或少量彩色点缀） |
| **景深** | 由明暗色调营造的景深 |

## Prompt Keywords
> 关键词行整段贴入外部生成服务的提示词，保留英文原文。
`pencil sketch, hand-drawn, graphite, charcoal, sketch style, rough drawing, crosshatch, tonal`

## 适用场景
- 建筑、概念艺术、线框风格插画、草稿预览
- 传达「进行中」或「幕后」的氛围
