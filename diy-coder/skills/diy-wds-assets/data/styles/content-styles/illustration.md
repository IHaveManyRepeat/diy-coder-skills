# 插画（Illustration）

## 概述
手工打造的数字插画——定制、温暖、品牌独一无二。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 中等——风格化，非照片写实 |
| **光照** | 平光或柔和明暗 |
| **质感** | 平滑，带细微颗粒感 |
| **色彩** | 品牌色板，可限定用色 |
| **景深** | 扁平至中等景深 |

## Prompt Keywords
> 关键词行整段贴入外部生成服务的提示词，保留英文原文。
`illustration, digital illustration, hand-drawn, custom art, vector style, flat illustration, character illustration`

## 适用场景
- 品牌叙事、新手引导流程、空状态页、错误页
- 摄影无法呈现的独特品牌辨识度

## Dimensions Guide
> 本节标题被流程引用，英文原文逐字保留。
- 点缀插画：400x400 到 800x800
- 场景插画：16:9 或自定义
- 图标式插画：64x64 到 256x256
