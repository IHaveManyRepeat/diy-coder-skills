# 超写实（Hyper-realistic）

## 概述
超越摄影——极致细节、完美光照、理想化的现实。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 最高——每处毛孔、每根纤维、每道反光都清晰可见 |
| **光照** | 完美的影棚光或电影级布光 |
| **质感** | 微观细节清晰可见 |
| **色彩** | 浓郁，经过强化但仍可信 |
| **景深** | 浅景深、焦外虚化 |

## Prompt Keywords
> **提示词关键词**——关键词行整段贴入外部生成服务的提示词，保留英文原文。
`hyper-realistic, ultra-detailed, 8K, macro detail, cinematic lighting, photographic, sharp focus, professional photography`

## 适用场景
- 奢侈品牌、美食摄影、汽车、珠宝
- 需要呈现高级感的首屏大图

## Dimensions Guide
> **尺寸指南**——本节标题被流程引用，英文原文逐字保留。
- 首屏大图：2560x1440 或更高
- 产品图：1:1，高分辨率
- 细节特写：微距裁切比例
