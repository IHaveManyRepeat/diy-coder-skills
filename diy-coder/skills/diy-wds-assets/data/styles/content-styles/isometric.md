# 等距视角（Isometric）

## 概述
以等距投影渲染的类 3D 物体——无透视，线条平行。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 中到高——几何形体干净利落 |
| **光照** | 平光或微妙的环境光 |
| **质感** | 平滑洁净的表面 |
| **色彩** | 品牌色板，可用鲜艳色彩 |
| **景深** | 等距投影（30 度夹角） |
