# 3D 渲染（3D Render）

## 概述
完整的 3D 渲染物体或场景，具备真实的材质、光照与景深层次。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 高——材质、反射与环境细节丰富 |
| **光照** | 影棚灯光或环境光 |
| **质感** | 真实材质（金属、玻璃、塑料、织物） |
| **色彩** | 全光谱，随材质而定 |
| **景深** | 完整 3D，带透视 |
