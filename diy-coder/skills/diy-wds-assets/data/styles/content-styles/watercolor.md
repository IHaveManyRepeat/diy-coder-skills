# 水彩（Watercolor）

## 概述
柔和流动的画面——透明渲染、边缘自然随性，富有手绘笔触感。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 低到中——写意而非精确 |
| **光照** | 柔和，经颜料漫射 |
| **质感** | 可见纸张纹理，边缘有颜料晕染 |
| **色彩** | 柔和、透明、自然融合 |
| **景深** | 氛围感——逐渐淡入白色 |
