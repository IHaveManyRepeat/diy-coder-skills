# 漫画（Comic Book）

## 概述
粗轮廓线、半调网点、对话气泡与动感十足的动作式构图。

## 渲染特征

| 属性 | 值 |
|----------|-------|
| **细节程度** | 中等——简化但富有表现力 |
| **光照** | 高对比，戏剧化阴影 |
| **质感** | 半调网点、Ben-Day 网点（美式漫画网点印刷法）、墨迹飞溅 |
| **色彩** | 大胆浓烈、饱和度高、限定色板 |
| **景深** | 扁平但带戏剧化透视 |

## Prompt Keywords
> **提示词**——英文行整段贴入外部生成服务；下行中文对照仅供理解。
`comic book, comic style, halftone, bold outlines, pop art, graphic novel, ink, dynamic, action`
中文对照：美式漫画、漫画风格、半调网点、粗描边、波普艺术、图像小说、墨线、动感、动作场面

## 适用场景
- 游戏、娱乐、年轻潮牌、营销活动
- 叙事序列、功能讲解、新手引导
