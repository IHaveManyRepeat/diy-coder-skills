# 编辑风（Editorial）

## 概述
杂志启发的设计，强调字体层级、编辑式版面与叙事表达。

## 视觉特征

| 属性 | 值 |
|----------|-------|
| **留白** | 策略性运用——像杂志跨页一样框住内容 |
| **配色** | 克制——常用单色加一抹点缀色 |
| **字体** | 层级分明，衬线标题，优雅的间距 |
| **边框** | 细分隔线、栏目分隔 |
| **阴影** | 极少 |
| **图像** | 满版出血摄影，编辑风格 |
| **图标** | 少量使用——由字体承载设计 |

## Prompt Keywords
> **提示词**——英文行整段贴入外部生成服务；下行中文对照仅供理解。
`editorial, magazine, typographic, sophisticated, storytelling, grid-based, print-inspired, refined`
中文对照：编辑排版、杂志感、字体编排、精致老练、叙事性、基于网格、印刷启发、雅致

## 适用场景
- 媒体、出版物、博客、奢侈品牌、文化机构
- 阅读体验至关重要的内容密集型网站

## 避免场景
- SaaS 仪表盘、商品繁多的电商、数据密集型应用
