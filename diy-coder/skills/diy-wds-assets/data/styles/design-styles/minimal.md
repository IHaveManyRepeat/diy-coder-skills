# 极简（Minimal）

## 概述
干净、宽敞的设计，最大化留白，克制地使用元素。

## 视觉特征

| 属性 | 值 |
|----------|-------|
| **留白** | 充裕——元素间从容呼吸 |
| **配色** | 单色＋一个点缀色 |
| **字体** | 无衬线，细至常规字重 |
| **边框** | 发丝线或无边框 |
| **阴影** | 无阴影或极轻微 |
| **图像** | 高对比、主体孤立突出 |
| **图标** | 线条图标，描边粗细一致 |

## Prompt Keywords
> **提示词**——英文行整段贴入外部生成服务；下行中文对照仅供理解。
`minimal, clean, whitespace, simple, uncluttered, modern, restrained, elegant simplicity`
中文对照：极简、干净、留白、简单、无杂乱、现代、克制、优雅的简洁

## 适用场景
- 作品集网站、奢侈品牌、SaaS 产品、个人网站
- 以文字为主的内容导向型版面

## 避免场景
- 密集数据展示、商品繁多的电商、活泼风格品牌
