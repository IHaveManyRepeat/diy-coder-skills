**Read (input):** `{output_dir}/wds-scenarios.yaml` 的 `scenarios[].pages[]` 的**页内交互**（动效需求：hero 动画 / 产品演示 / 微交互 / 背景视频 / 解说序列）；`{output_dir}/wds-design-system.yaml` 的**动效令牌**（时长刻度 / 缓动曲线 / 过渡类型）；`{output_dir}/assets/` 下可被动画化的静态件（自产回读）。

你是**动效生产的主持人**（源 `steps-v/` 五步）。动效是本技能里**唯一有性能与无障碍硬门**的活动——好看但卡、或者不尊重「减少动态效果」偏好，就是不合格。

## 第 2 步 —— 盘点与复杂度分级（源 `steps-v/step-02`）

**先问清**：「全做、按类型、点名，还是只做关键路径上的？」

**资产表**：逐条写 **名 / 页 / 类型 / 时长 / 格式**（格式从 MP4 / WebM / CSS / Lottie / SVG anim 里选）。

**复杂度四级**（源侧原口径，写入 `items[].variant`）——**这一级直接决定第 4 步走哪条分支、也决定体量预算**：
| 级 | 判据 | 体量目标 |
| --- | --- | --- |
| `S` Simple | CSS / SVG 能做完的（淡入、位移、旋转） | `<10KB` |
| `M` Medium | 要 Lottie 的（多段序列、路径动画） | `<50KB` |
| `C` Complex | 要成片的（产品演示、解说） | `<10MB` |
| `G` Generated | 要外部服务生成的 AI 视频 | `<2MB` |

**范围四选一**（写进 `activities[AS-06].scope`）：`all` / `type` / `select` / `priority`。

**产出键**：`activities[AS-06].items[]`（`id: AS-06.<m>` 递增；`name` / `pages` / `variant`（复杂度级）/ `size`（尺寸或 `"css"`、`"lottie"`）/ `spec` 非空）。

**检查点（六拍）**：① 生成资产表与分级 → ② 落盘 `items[]` / `scope` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 3 步 —— 动效人格与计时（源 `steps-v/step-03`）

## 第 4 步 —— 按复杂度路由生成（源 `steps-v/step-04`）

**先问清**：「按分级结果从 `S` 级开始做，还是先啃复杂的？」

**四级各走各的分支**（源侧原口径，**这是本活动的核心路由**）：
- `S` **Simple** → **产 CSS / SVG 关键帧代码**（直接写进 `assets/motion/css/` 或 `svg/`，可跑、可看）；
- `M` **Medium** → **产 Lottie 描述**（可出 JSON，落 `assets/motion/lottie/`）；
- `C` **Complex** → **产故事板 + 分镜单 + 制作指导**（不产片；这是提示词形态的产物，落 `assets/motion/prompts/`）；
- `G` **Generated** → **产 AI 视频提示词**（时长 / 主体 / 运动 / 调性 / 风格 / 色板 / 尺寸 / FPS / 循环 / 参考帧）——**本技能不调服务**（裁定 6），生成归用户。

**提示词整段给出**（`items[].prompt`）：`S`/`M` 级的 `prompt` 写的是**实现规格**（关键帧序列 / 路径描述），`C`/`G` 级写的是**生成提示词**。两种都在同一个字段，靠 `variant`（复杂度级）区分。

**逐件预览校时感**（源侧口径）：`S`/`M` 级的代码/JSON 要**真的在浏览器里跑一遍看时感**（源 mimir 线「UI 每次改动都要在浏览器里验证」的落地），不是只看代码对不对。

**产出键**：`items[].prompt` / `prompt_lang` / `items[].assets[]`（`S`/`M` 级在此步就有产物）；`prompts[]` 追加（`C`/`G` 级必加、`S`/`M` 级可加）。

**检查点（六拍）**：① 生成各级产物/提示词 → ② 落盘 `prompt` / `assets` / `prompts[]` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 5 步 —— 一致性与性能无障碍评审（源 `steps-v/step-05`）

**先问清**：「（生成件 / 代码放进来后）哪些要调？」

**动效一致五查**（源侧原口径）：计时（同类交互同时长）｜ 缓动（同族）｜ 方向（进出方向不打架）｜ **无互相打架**（两个动效不要抢同一块注意力）｜ 循环无缝（循环动画的头尾接得上）。

**性能三查**（源侧原口径）：
- [ ] **体量达标**——按第 2 步的级别对表（`S<10KB` / `M<50KB` / `C<10MB` / `G<2MB`）
- [ ] **无过度复杂**——能用 `transform` / `opacity` 解决的不要动画 `width` / `top`
- [ ] **GPU 属性 + 折叠下懒加载**——动画属性走合成器；首屏下的动画延迟加载

**无障碍四查**（源侧原口径，**硬门**）：
- [ ] **尊重 `prefers-reduced-motion`**——用户开了「减少动态效果」时的降级路径要有（通常是直接到终态）
- [ ] **无每秒 3 次以上的闪烁**（癫痫风险，硬红线）
- [ ] **不干扰阅读**——背景动效不能压正文可读性
- [ ] **视频可暂停 + 提供静态替代**

**分支**：`[A]` 全批通过 ｜ `[R]` 重生指定 ｜ `[T]` 调时 ｜ `[E]` 调缓动 ｜ `[C]` 整页场景预览 ｜ `[P]` 性能报告。

**落盘口径**：按格式分目录落 `{output_dir}/assets/motion/`（`css/` `svg/` `lottie/` `video/`）；`items[].assets[].path` 存相对路径。
**已知缺口（登记）**：`viewer.py` 只扫顶层 `*.yaml` → `assets/motion/` 下的产物**渲染不到**。

**产出键**：`items[].assets[]` + `items[].review`（一致五查 + 性能三查 + 无障碍四查 + `verdict`）+ `activities[AS-06].status: 已评审`。

**收尾动作**：更新活动级 `status` 到 `已评审`；一句话说明本活动的 `C`/`G` 级与第 8 步（演示）的 `EX` 配方共界——解说视频的**内容脚本**归第 8 步、**动效落盘**走本活动的 `motion/` 通道；本文件到此结束——读 `steps/07-content.md` 继续，或回活动菜单。

**检查点（六拍）**：① 生成评审表（含体量实测）→ ② 落盘 `assets` / `review` / 活动 `status` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。
