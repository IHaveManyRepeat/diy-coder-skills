# 生成提示词骨架（导出包用）

> **出处**：改造自源 `wds-6-asset-generation/templates/stitch-prompt.template.md`（174 行，随 `[E]` 与那家服务一并裁撤的孤岛文件）。**改造点（裁定 6）**：① 去 **Stitch** 服务绑定（模板头、服务名字样、平台专属字段全去）；② 去**免费额度**段（那是某家服务的计费口径，与本技能无关）；③ 通用化为**任何外部生成服务的落地页**。
>
> **用法**：`steps/09-finish.md` 第 2 步逐条把 `prompts[]` 条目渲染成一份 `.md`，落 `{output_dir}/assets/<活动>/prompts/<条目名>.md`。用户拿这份文件去任意服务生成，产物回填到 `{output_dir}/assets/<活动>/`。

---

## 一、填之前的三条纪律

1. **不要粘贴原始规格**——规格是给人看的（含 ID、双语、技术注记），生成服务不需要这些。按下面的骨架**重写**。
2. **只保留一种语言**——用 `document_output_language`；不要把双语对照塞进去。
3. **丢技术细节**——机器 ID（`SC-01.P1`）、内部令牌键名、文件路径**不进提示词**（它们是给人对表的）；把它们的**值**写进去（`#2563EB` 而不是 `color.primary.600`）。

## 二、骨架（照此填，不留空段）

```
=== 项目语境 ===

产品：{产品名}——{一句话定位}
受众：{目标用户，来自 wds-brief 的目标用户}
品牌气质：{2–3 个形容词}
场合：{这份资产给谁看、在哪看}

=== 设计系统 ===

颜色：
- 背景：{色名}（{hex}）
- 主行动：{色名}（{hex}）
- 正文：{色名}（{hex}）
- 次要文字：{色名}（{hex}）
- 成功 / 警示：{hex}

字体：
- 字族：{font family}
- 标题：{字重}，{特征}
- 正文：{字重}，{字号}

组件样式（若为本套件的 UI 件）：
- 按钮：{圆角 / 渐变 / 阴影 等描述}
- 输入框：{边框 / 焦点态}
- 卡片：{描述}

=== 本件规格 ===

资产：{AS-<nn>.<m>} {资产名}
用途：{一句话——这个资产要干什么}
页面锚：{它服务哪一页（页名可写，ID 不进提示词）}

结构：
1. {区块 1}：{元素}
2. {区块 2}：{元素}
3. {区块 3}：{元素}

关键元素：
- {元素 1}："{真实文案}"
- {元素 2}："{真实文案}"

关键交互：
- 主行动：{点了会怎样}
- 次行动：{点了会怎样}

=== 当前状态注记 ===

{哪些地方现在用的是默认样式、生成时应改成本套件的样式}

=== 生成指令 ===

按以下要求生成：
- 视觉语言：{所选 design-styles 卡的 Prompt Keywords，英文原样}
- 成像技法：{所选 content-styles 卡的 Prompt Keywords，英文原样}
- 版式：{配方卡的 Format Characteristics 逐条：比例 / 密度 / 字阶 / 转场}
- 尺寸：{1440x900 / 390x844 / 16:9 等}

画幅：{桌面 1440px / 移动 390px}
```

## 三、粘贴前 9 条自检（源侧清单去服务绑定后的版本）

- [ ] 三段结构齐（项目语境 / 设计系统 / 本件规格）
- [ ] 色值都是 hex，不是令牌键名
- [ ] 字体写了字族 + 字重 + 字号（不是「现代感字体」）
- [ ] 结构写成了**有序**区块（不是「经典的落地页布局」）
- [ ] 元素带**真实文案**（不是 `heading text`）
- [ ] 只有一种语言
- [ ] 没带机器 ID、内部键名、文件路径
- [ ] 尺寸与画幅明确
- [ ] 风格关键词是**英文原样**（没被翻成中文）

## 四、回填约定（裁定 12）

生成结果放回 **`{output_dir}/assets/<活动>/`**（**子目录、不入库**），并把路径写进对应 `items[].assets[].path` + `format`——**YAML 只存路径引用，不嵌二进制**。
**已知缺口**：`viewer.py` 只扫 `output_dir` 顶层 `*.yaml` → `assets/<活动>/` 下的产物**渲染不到**（评审结论只在 `wds-assets.yaml` 里可见）。
