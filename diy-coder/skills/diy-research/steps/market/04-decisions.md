## 要写的 findings

每个 `area` 一条 `findings[]` 条目，随该次检索落地即写：

| `area` | 该断言说什么 |
| --- | --- |
| `decision-process` | 阶段、时长、复杂度、评估方式 |
| `decision-factors` | 主要与次要标准、如何权衡、如何变化 |
| `journey-mapping` | 认知 → 考虑 → 决策 → 购买 → 购后 |
| `touchpoints` | 线上与线下触点、信息来源 |
| `information-gathering` | 调研方式、可信来源、耗时、评估标准 |
| `influencers` | 同伴、专家、媒体、社会认同的影响 |
| `purchase-factors` | 即时与延迟动因、品牌忠诚、价格敏感度 |
| `decision-optimizations` | 减少摩擦、建立信任、转化、忠诚 |

## 方法

- 必须联网检索——决策研究、旅程映射方法论、购买标准分析。
- 每条 `critical claim` 两个独立来源；冲突摆出来，不悄悄消解。
- 每条 finding 的 `confidence`：`高` / `中` / `低`。
- 旅程类断言锚在所研主题上，不套通用漏斗模板。
