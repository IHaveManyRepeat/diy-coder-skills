## 要写的 findings

每个 `area` 一条 `findings[]` 条目，随该次检索落地即写：

| `area` | 该断言说什么 |
| --- | --- |
| `key-players` | 领先者、主要竞争者、新兴玩家、全球与区域的分野 |
| `market-share-positioning` | 份额分布、定位、价值主张、所服务的细分 |
| `strategies-differentiation` | 成本领先、差异化、聚焦细分、创新路径 |
| `business-models` | 各玩家怎么赚钱、收入来源、客户关系模式 |
| `dynamics-entry-barriers` | 进入壁垒、竞争烈度、整合趋势、转换成本 |
| `ecosystem-partnerships` | 供应商、分销渠道、技术联盟、价值链控制 |

## 方法

- 必须联网检索——竞争情报报告、公司官网、年报、投资者材料。
- 公司自述是来源、不是事实：定位与份额类断言独立佐证。
- 每条 `critical claim` 两个独立来源；冲突两边都摆、都引。
- 每条 finding 的 `confidence`：`高` / `中` / `低`。
