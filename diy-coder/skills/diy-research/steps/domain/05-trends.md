## 要写的 findings

每个 `area` 一条 `findings[]` 条目，随该次检索落地即写：

| `area` | 该断言说什么 |
| --- | --- |
| `emerging-tech` | AI/ML/自动化的影响、颠覆性技术、突破 |
| `digital-transformation` | 采用趋势、商业模式演进、客户体验变化 |
| `innovation-patterns` | 该行业的创新如何发生、研发方向 |
| `future-outlook` | 路线图与预测——近期（1–2 年）、中期（3–5 年）、长期（5 年以上） |
| `implementation-opportunities` | 当下就能落地的技术机会 |
| `challenges-risks` | 采用障碍、颠覆风险、区域差异 |
| `recommendations` | 技术采用策略、创新路线图、风险缓解 |

`recommendations` 是通往综合步的桥：照旧写成带来源的 findings，第 6 步把最重要的几条提进 `synthesis.key_points`。

## 方法

- 必须联网检索——前沿技术报道、创新案例、采用时间线研究。
- 把有记录的采用与推测分开：前瞻性断言要点名其时间视野，除非多个来源指向同一判断，否则只停 `低`/`中` 置信。
- 每条 `critical claim` 两个独立来源；冲突两边都摆、都引。
- 每条 finding 的 `confidence`：`高` / `中` / `低`。
