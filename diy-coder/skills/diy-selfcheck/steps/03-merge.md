# Step 3 — 合并去重分级（Merge）

Progress: `冻结与编排判定 → 三机制派发 → [合并去重分级] → 处置与复扫 → 收口呈核`

**Read (input):** `spec-scan/part-*.md` 全部片产物。
**Write (output):** A 部分分级表（进报告草稿）。

## 去重

同一问题被 2–3 片独立发现 → **合并为一条，标注命中片数**。判定「同一问题」看落点与实质，不看措辞——措辞差异恰恰是独立命中的证据。

## 置信度

- **三片独立命中 → 置信度最高**（B3–B7 实证：这类条全是阻断或高），处置排序置顶。
- 单片命中不是低置信——但单片独家的「数值与出处硬错」要复核一遍再定级。

## 分级

`阻断`（两种理解会导致完全不同的实现）/ `建议`（照做能过但埋雷）/ `观察`（值得记录不阻塞）。不确定就标 `建议`，别升 `阻断`。分级表列：`# / 严重度 / 命中片 / finding 一句 / 落点`。

## 播报与下一步

一行播报：`原始 X 条 → 合并去重后 Y 条（阻断 a / 建议 b / 观察 c；交叉命中 d 条，三片同中 e 条）`。读 `steps/04-dispose.md`。
