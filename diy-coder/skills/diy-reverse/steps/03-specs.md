## 第 1 步 —— 页排序与六段规格（源 step-03 第 1–2 指令）

**先说清为什么**：讲清「为什么要挑着做而不是一页不落」——先做最有代表性的一页，学到的模式能复用到其余页；逐页重做一遍是最贵的错。用你自己的话讲。

### 1.1 页排序（源 step-03 第 1 指令）

- 从**最有代表性 / 最基础**的页起手；
- 把共用布局的页**归组**；
- 近乎相同的页**只写一页 + 注明变体**（不重复写 N 遍）。

### 1.2 六段规格（源 step-03 第 2 指令，**六段全保**）

每页六段，落进 `pages[]` 的对应键：

| 段 | 落点 |
| --- | --- |
| 总览（用途 / URL / 类型） | `name` / `route` |
| 布局结构（桌面版式、自上而下的区块） | 结构稿正文 + 会话呈出 |
| 组件清单（组件 / 位置 / 变体 / 备注） | 结构稿正文 + `02-explore` 的组件清单 |
| 内容策略（标题模式、正文、CTA 用语、图像） | 结构稿正文 |
| 响应式行为（断点变化） | 结构稿正文 |
| 交互（悬停、点击、滚动、校验、弹窗） | `states[]` 四态 + `signals` |

**`route` 照抄目标的路由形态**（`/pricing` 之类）——它是「一页一条记录」的连接键，不翻译、不改写。

**落盘**：`pages[]` 记录逐条写入（`id` / `name` / `route` 三键先落，`states` 与 `prototype` 在第 3 步补齐）。

**检查点（六拍）**：① 生成 → ② 落盘 → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。本步：② 落盘（`pages[]` 三键）；④ 呈出页排序与首几页的六段。

## 第 2 步 —— 场景大纲与组件交叉引用（源 step-03 第 3–4 指令）

**先说清为什么**：讲清「为什么多页流程要单独写成一串」——单页规格说不清「用户从哪来、到哪去」，而那正是重建时最容易漏掉的东西。用你自己的话讲。

### 2.1 场景大纲（源 step-03 第 3 指令）

目标有多页流程（注册 / 结账 / 上手引导）时，逐个写成**场景大纲**：步骤 / 成功路径 / 错误态。**落点 = 会话呈出**（既有 schema 无场景段）——它是页规格之间的连接叙述，不另立产物文件。

### 2.2 组件交叉引用（源 step-03 第 4 指令）

逐页核对：**规格里提到的每个组件都要在 `02-explore` 的组件清单里**；出现「规格里有、清单里没有」的组件 → **回清单补**（或判为一次性组合并注明），**不许只在规格里凭空出现**。

**落盘**：交叉引用结论 + 组件清单增补（会话）。

**检查点（六拍）**：① 生成 → ② 落盘 → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。本步：② 落盘（组件清单增补）；④ 呈出场景大纲与交叉引用结论。 四选项同第 1 步。

读全并照做本文件 `## 第 3 步 —— 落 pages[] 与结构稿`。

## 第 3 步 —— 落 `pages[]` 与结构稿

**先说清为什么**：讲清「为什么结构稿必须由你画出来」——既有 schema 的 `validate` 要求每页的结构稿在磁盘上真实存在；而**画**（而不是复制）恰好也是「不抄像素」的执行形态。用你自己的话讲。

### 3.1 页 ID 铸号（**既有 schema 的形态，裁定 13**）

`pages[].id` 取 `P-<n>`：**从 `P-1` 起顺序铸、不重编不复用**；引擎核形态（非法判 `ENUM_INVALID`）、唯一性（重号 `DUPLICATE_ID`）与顺序性（跳号 / 乱序 `SET_MISMATCH`）。**不得用 WDS 线的记录 ID 形态**（那是另一条线的产物）。

### 3.2 四态与信号

每页必带 `悬停` / `空态` / `加载中` / `错误` 四态，**每态至少一条非色彩信号**（`图标` / `文字` / `形状` / `动效` 一类；`色彩` 独自出现判违规——颜色不单独承载语义）。观察不到的状态按最小真实信号记并注明（同 `02-explore` 2.2）。

### 3.3 结构稿（`prototypes/<页 id>.html`）

逐页写一份**你自己画的**线框 HTML：区块顺序、landmark、四条交互状态的位置。两条硬要求：

- **文件名与 `id` 同源**（`P-1.html` ↔ `P-1`；不同源判 `SET_MISMATCH`）；
- **头部注释记提取来源**：`<!-- 提取来源: <url> / <截图名> · 采集日 YYYY-MM-DD -->`（`design.yaml` 无来源字段，本批不新增——登记为 C·3 的 schema 扩充项）。

**不搬目标的代码与资产**：结构稿用**你自己的**最小 HTML 画结构，**不复制**目标站的 HTML / CSS / 字体 / 图片（源 IP 纪律；`validate` 另会核 h1 唯一、`input` 带 label、`img` 带 alt 三项语义 HTML）。

**落盘**：`pages[]` 的 `states` 与 `prototype` + 逐页结构稿。

**检查点（六拍）**：① 生成 → ② 落盘 → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。本步：② 落盘（`states` / `prototype` / 结构稿文件）；④ 呈出逐页记录与结构稿索引。 四选项同第 1 步。

**收尾与路由**：页规格齐了，读 `./04-extract-tokens.md` 把 token 三段落定并收口。

本文件到此结束，不再回头。
