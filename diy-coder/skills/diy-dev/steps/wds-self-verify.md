# Step — 浏览器强制门（自验证）

Progress: `[1 起环境与捕基线] → [2 逐条核对] → [3 不合规当场修] → [4 呈报定性四项] → 路由`

**Read (input):** `{output_dir}/design.yaml` 该页 `states[].signals`（判据唯一真源）；实现/预览入口（框架开发服务器或 `prototypes/<页 id>.html`）；Playwright（MCP 或脚本化）；用户在本文件各步的回答。
**Write (output):** 会话内的核对表（逐条 actual vs expected + pass/fail）与**跳过留名行**。不改任何 YAML、不改判据——判据不成立 → 停下路由 `diy-design`。

**门的三要素（冻结，与 `diy-design` 的 `steps/prototype-loop.md` 同一套）**：判据 = 该页 `states[].signals`；验手段 = Playwright（MCP 或脚本化）；强制语义 = 未过**不得呈给用户**。同一条门在 `diy-review` 的 WDS 路径上再独立跑一遍（它不采信本技能的自述），两端判据一致、不各说一套。

## 第 1 步 —— 起环境与捕基线

1. 起页面（开发服务器 / 构建产物 / 结构稿 HTML 三选一，按项目形态）→ 打开 → 设目标视口（页面有响应式面时，移动 375 / 平板 768 / 桌面 1024 各核一遍：布局堆叠、无横向滚动、触控目标 ≥44px）。**MCP 形态下 `file://` 被策略拦截**——结构稿 HTML 须起本地静态服务（如 `python -m http.server`）后再验，脚本化 Playwright 可直接读文件；这条拦截**不算**「环境不可用」，不触发裁定 21 分支。
2. **改既有功能时先捕基线**（改前做）：截图 + 记下关键可测值（文本、色值、尺寸、可见性）与各交互的现状；实现后比对，**确认只发生预期改动**。新页无基线，直接进第 2 步。

## 第 2 步 —— 逐条核对（可测量项归 agent）

1. 逐条判据：定位元素 → 读**实际值**（文本 / computed style / 尺寸 / 可见性）→ 与 `states[].signals` 逐字比对 → 记 pass/fail。
2. 每态至少一条**非色彩**信号在场（图标 / 文字 / 形状 / 动效）；色与字号走 token 变量（`var(--*)`），无裸色值。
3. 每条一行叙述 **actual vs expected**——`actual` 是读回来的值，不是推断；**绝不请用户核 agent 自己能量到的项**。

## 第 3 步 —— 不合规当场修，改完重验

不合规 → 回 `./wds-implement.md` 对应工作项改，改完**重跑第 2 步**，直到逐条 pass（**允许自环，页状态不变**：自环记录留会话回报，不写 YAML——`revisions[]` 只由 `transition` 在破坏性边上追加）。**不削弱判据、不把缺陷带进呈报。**

## 第 4 步 —— 呈报（定性四项归人）

门**逐条过完之后**才呈人；呈出的是**定性四项**：Flow 感觉 / 视觉层级 / 清晰度 / 一致性（源 `4d:78-82`）。用户回三种之一：

| 分支 | 处置 |
| --- | --- |
| **批准** | → 读 `./wds-finalize.md` 走状态写回与交棒 |
| **问题**（`Issue`） | 报根因 → 回 `./wds-implement.md` 修 → **重走本门** → 重新呈报 |
| **改进**（`Improvement`） | 问一句「要不要回写进规格」：**要** → 停下并路由 `diy-design`（规格先于稿；`design.yaml` 写权不在本技能）；**不要** → 只改实现，改完重走本门 |

## 环境不可用（裁定 21，冻结）

探测不到 Playwright（MCP 或可执行）→ **停下如实上报**：说明探测方式与结论，**把选择权交用户**——① 安装/启用后重跑，或 ② 用户明确同意本次跳过该门。

- **不得静默降级**：不问就跳过 = 违规。
- **不得无条件硬停**：用户已同意跳过仍拒绝执行 = 把门变成僵局。
- **跳过须留名**：哪一页 / 谁的授权 / 补验计划——写进回报与呈报（**跳过是用户的决定，不是 agent 的裁量**）；不另立产物键（`design.yaml` schema 本批冻结）。
- 本条属**副作用①档**（程序化测试动作）：执行失败走本节的「停下上报 + 交用户裁决」，**不适用**②档的「无头跳过不阻塞」（②档只给 viewer 打开浏览器这类 GUI 展示动作）。

## 收尾与路由

门过 → `./wds-finalize.md`。本文件到此结束，不再回头。
