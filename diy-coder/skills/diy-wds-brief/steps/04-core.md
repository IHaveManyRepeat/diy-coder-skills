# Step 4 — 简报核心段（Core）

Progress: `[1 愿景] → 2 定位 → 3 商业模式 → 4 B2B 客户 → 5 目标用户 → 6 产品概念 → 7 成功指标 → 8 竞争格局 → 9 约束 → 10 平台策略 → 11 语气 → 12 定稿`

**Read (input):** 上一个文件的放行（`intake.stage` 已推进到 `核心`）；`intake` 分诊结论与 `client_profile`（`stakes` / `working_relationship` 决定问话深浅）；`alignment` 十节（走了对齐时作背景，**取用而不重问**）；用户在本文件各步的回答。
**Write (output):** `brief.core` 各键；`intake.stage: 核心`；给用户的逐节呈出与定稿呈批。

你是**战略简报的主持人**（源 wds-1-project-brief 的 Phase 1 前半）。核心段的纪律只有一条：**用户负责讲，你负责综合**——源侧反复强调「**不要叫用户写愿景声明**」，那是你的活。

**会话纪律**（源侧四步子流程，愿景 / 定位两步**都走这四拍**）：① **开场**——把问题抛出去，请用户大声想；② **探索**——听出目的、影响、野心的信号，追问到本质为止；③ **回述确认**——把你的理解讲回去，拿到确认再往下；④ **综合落盘**——你写声明，用户确认。**不得跳拍**，尤其不得跳第 ③ 拍。

**档位纪律**：本文件各节的〔可跳过〕标记只在 `brief_level: simplified` 时生效——简化档走**愿景 / 目标用户 / 约束**三节 + 定稿；其余节由用户点头后整节跳过（键留空，`check --final` 按简化档键表核对）。

## 第 1 步 —— 愿景（源 step-02）

**开场问句**：你现在在做的这个东西，**是什么**？**为什么它重要**？（请对方大声想，别急着总结）

**探索期听三样信号**：**目的**（做这个是冲着什么去的）/ **影响**（成了以后世界有什么不一样）/ **野心**（想做多大、想站到哪儿）。听到含糊处追问：「这话再具体一点是什么样？」

**不要问的**：不要问「你的愿景声明是什么」；不要把「提升用户体验」这类没有主语的句子当答案收下。

**落盘**：`brief.core.vision`——**你综合**出一句愿景声明 + 一两句背景（源侧：synthesis 由你写，用户只确认）。

**检查点（六拍）**：① 生成 → ② 落 `brief.core.vision` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。

## 第 3 步 —— 商业模式（源 step-05）

**问**：这门生意**向谁收钱**？**B2B**（卖给企业）/ **B2C**（卖给个人）/ **两者都有**？

**追问一句为什么**：这个选择对产品策略意味着什么（源侧口径：B2B 与 B2C 的决策链、信任建立方式、内容深度都不同）。

**条件路由**：选 **B2B 或 B2B+B2C** → 下一节必走（第 4 步）；**纯 B2C** → 第 4 步整节跳过（`brief.core.business_customers` 留空，`check` 不要求）。

**检查点（六拍）**：① 生成 → ② 落 `business_model` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 8 步 —— 竞争格局（源 step-09）

**问**：**今天大家用什么凑合**（先把现有做法，而不是竞品公司，摆出来）？**他们为什么可能不换**？这东西**凭什么真的更好**？我们**不讲道理的优势**（unfair advantage）是什么？

**口径**：**至少两个替代方案**（含「不改，继续用现在这套」这一项）；「更好」要落成具体的差异，不是形容词。

**落盘**：`brief.core.competitive_landscape`（替代方案 + 各自留客理由 + 我方差异 / 优势）。

〔简化档：本节标〔可跳过〕。〕

**检查点（六拍）**：① 生成 → ② 落 `competitive_landscape` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。
