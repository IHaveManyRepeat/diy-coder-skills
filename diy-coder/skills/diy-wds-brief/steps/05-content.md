## 第 1 步 —— 内容段启动（源 step-13）

## 第 2 步 —— 品牌人格（源 step-14）

**问**：这个品牌**像什么样的人**？给**至少三个**人格词——**要具体到能反驳**（源侧质检的硬要求：不许用「专业」「友好」这种谁都能贴的词）。

**追问法**：每给一个词，追一句「那它的反面是什么？」——反面越清晰，这个词越可用。

**落盘**：`brief.content.content_language.personality`（人格词 + 各自的反面与一句解释）。

## 第 3 步 —— 语气（源 step-15）

**问**：人格**落到文字上**是什么样（源侧口径：人格是「是什么」，语气是「怎么写出来」）？

**要三样**：① **核心语气**一句；② **语气光谱**（正式 ↔ 轻松、克制 ↔ 热情……两端各给一个例子）；③ **我们会这么说 / 我们绝不说**对照表（各 2–3 条）。

**追问法**：把同一句话用两种极端语气各写一遍给用户挑——挑完再问「为什么不是另一个」。

**落盘**：`brief.content.content_language.tone`（核心语气 + 光谱 + 对照表）。

〔简化档：本节标〔可跳过〕。〕

**检查点（六拍）**：① 生成 → ② 落 `tone` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 4 步 —— 语言（源 step-16）

**问**：**主语言**是什么？**还要支持哪些语言**？**翻译怎么走**（人工 / 机器 / 人机混合）？**称呼的正式度**怎么定（你/您、tu/vous、you/thou）？

**追问法**：多语言时追问一句「哪些内容必须专业翻译、哪些可以机翻」——源侧口径：这直接决定内容维护成本与 SEO 策略。

**落盘**：`brief.content.content_language.languages`（主语言 + 附加语言 + 翻译路径 + 正式度）。

〔简化档：**本节必走**——是简化档在本段的唯一必填键。〕

## 第 5 步 —— SEO 关键词（源 step-17）

**问**：用户**会怎么搜**？**哪些词必须抢**？**每个词打算挂在哪一页**？本地 SEO 有要求吗（门店 / 区域）？要不要做结构化数据？

**要四样**（源侧 SEO 四要素）：① 主关键词（**至少 3 条**，每条标搜索意图：信息型 / 导航型 / 交易型）② **页-词映射**（每个主词至少挂一页；**两页不得抢同一个主词**）③ 长尾变体 ④ URL 结构与本地 SEO（如适用）。

**外部指南**：源侧此处读一份 `seo-strategy-guide.md`——**该文件在 diy 侧不存在**（源侧路径为 `_bmad/` 共享面，census-1 §5-① 第 7 条）→ **本批内联进本节**：先定意图分层（信息 / 导航 / 交易），再按「一词一页」落映射，最后补长尾。

**落盘**：`brief.content.content_language.seo_keywords`（词表 + 意图 + 页映射 + 长尾 + URL / 本地 SEO）。

**检查点（六拍）**：① 生成 → ② 落 `seo_keywords` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。
