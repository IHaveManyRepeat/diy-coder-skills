## 第 1 步 —— 灵感工坊（源 step-19）

**先说清为什么**：讲清「为什么先看别人再谈自己」——用户说「我要高级感」时你抓不到东西，但让他指着一个具体站点说「要这个的呼吸感」就抓到了。用你自己的话讲。

**做法**：请用户给 **2–6 个参考站**（他自己的竞品、他喜欢的、他讨厌的都可以）。逐站问三句：

- 这站里你**具体看上**的是什么？（不是「我喜欢这个站」——要指到某一块）
- 这块**为什么**对你有用？
- 如果**只取一样**，取哪样？

**落盘**：`brief.visual.visual_direction.inspiration`（站点 + 逐站要点 + 提炼出的设计原则）。

**检查点（六拍）**：① 生成 → ② 落 `inspiration` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。

## 第 2 步 —— 视觉段启动与既有品牌（源 step-20 + step-21）

**先说清为什么**：讲清「为什么先盘家底」——已有的 logo、色号、字体要么被尊重、要么被明确废弃，没有第三条路。用你自己的话讲。

**启动**：一句话交代本段要产出什么（六维视觉方向），以及「不知道的可以留空，不猜」。

**问**：**有没有现成的视觉识别**（logo / 品牌手册 / 色板 / 字体规范）？

- **有** → 逐样登记，并追问两条**约束**：哪些**必须保留**（客户市场已认的资产）？哪些**可以动**（已经过时的部分）？
- **没有** → 明确落一条「无既有品牌资产」（源侧质检要求这一节在场，不许缺节）。

**落盘**：`brief.visual.visual_direction.existing_brand`（资产清单 + 约束）。

**检查点（六拍）**：① 生成 → ② 落 `existing_brand` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 3 步 —— 参考与视觉情绪（源 step-22）

**问**：除了第 1 步那几站，还有**别的想要的样子**吗？**整体情绪**该是什么（安静、热烈、克制、张扬、精密、手作……）？**要避免**的视觉印象有哪些（这往往比想要的更好问）？

**口径**：第 1 步问**具体要素**，本步问**整体情绪**——两节都要落，不可合并（源侧分两步就是为把「抄哪块」和「像什么气质」分开）。**至少 2 个参考站**且**每站要写清取什么**（源侧质检硬要求，不许写「我喜欢这个站」）。

**落盘**：`brief.visual.visual_direction.references`（参考站 + 视觉情绪 + 避免项）。

**检查点（六拍）**：① 生成 → ② 落 `references` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。

## 第 4 步 —— 设计风格（源 step-23）

**术语内联（源侧死链的替代）**——从每组挑，也可以自造更准的词：

- **UI 风格**：极简 / 编辑风（editorial） / 新粗野（neubrutalism） / 玻璃拟态（glassmorphism） / 拟物 / 扁平 / 拟真（skeuomorphic） / 手作拼贴
- **设计美学**：瑞士国际主义 / 包豪斯 / 日式侘寂 / 孟菲斯 / Y2K / 复古未来 / 极繁
- **色彩术语**：主色 / 辅色 / 强调色 / 中性阶 / 语义色（成功·警告·错误）；冷暖倾向；对比策略（高对比 vs 同色系）；色彩方案类型（单色 / 类比 / 互补 / 三分）
- **字体分类**：衬线 / 无衬线 / 板衬线 / 等宽 / 手写 / 展示体；字重与字距策略；中英混排口径

**问**：四个组各挑 1–3 个词，并各追一句**为什么是它**（说不出为什么的词不留）。

**落盘**：`brief.visual.visual_direction.design_style`（UI 风格 + 美学 + 色彩方向 + 字体方向，各含理由）。**下游 wds 线的设计系统与设计段都读这一键当词表**——用词要能被外人读懂。

## 第 5 步 —— 布局与特效（源 step-24）

**术语内联**——**布局**：单列 / 双列 / 十二栏网格 / 破格（grid-breaking） / 杂志式 / 卡片流 / 分屏 / 全屏滚动叙事。**特效**：微交互 / 视差 / 滚动触发动画 / 形变过渡 / 粒子 / 滤镜 / 3D 变换。

**问**：页面**怎么排**？关键布局元素有哪些（导航形态、首屏结构、区块节奏）？**动效用什么、用在哪、什么节奏**？

**平台约束要一起看**：核心段的 `platform_strategy` 若含低端机 / 老浏览器，重型特效当场标为「视性能降级」（源侧口径：带着平台约束做特效决策）。

**落盘**：`brief.visual.visual_direction.layout_effects`（布局法 + 关键元素 + 特效清单与用法 + 性能降级口）。

**检查点（六拍）**：① 生成 → ② 落 `layout_effects` → ③ 分隔 → ④ 呈出 → ⑤ 出四选项 → ⑥ 等响应。四选项同第 1 步。
