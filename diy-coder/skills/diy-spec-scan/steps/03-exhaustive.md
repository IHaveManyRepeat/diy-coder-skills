# Step 3 — 穷举执行（Exhaustive）

Progress: `定位与切分 → 预演执行 → [穷举] → 交叉验证 → 落盘与交付`

**Read (input):** 草稿记录里的 `units` 清单与已有 findings（去重与标记用）；各单元对应的目标文件片段。
**Write (output):** findings 追加进草稿记录（`source: [穷举]`）；仍为 `false` 的 `scanned` 标记与重算后的 `summary`；给用户的进度播报。

## 你要做什么

方法驱动的路径/边界枚举——不顺推、不扮演实现者，机械地把规格里的分支与边界走一遍，只报**没被处置的路径**：

- **边界从内容自身推，不套固定清单**——规格里出现什么分支就枚举什么分支，不拿预设类别去套，也不为凑类别硬找。
- **枚举对象（示例）**：规格内每个「若 / 除非 / 默认 / 边界」条件句；流程的每个岔口、异常出口、可选项；数据的空 / 越界 / 重复形态。一句带多条分支就逐条走。
- **每条分支问一句**：走到这里，规格给了处置吗？给了 → 静默丢弃（处置过的不报）；没给 → 记一条 finding。
- **零命中合法**：全部路径都有处置，本步零 findings 是合法完成——如实播报，不凑数。

`type` 八类：`输入不明` / `输出不明` / `分支无定义` / `时序不明` / `术语冲突` / `直接矛盾` / `接口缺口` / `隐含假设`。穷举命中多半落 `分支无定义`（岔口 / 边界没给处置）与 `隐含假设`（答得上来靠的是规格外知识）。

**severity 判据**：`阻断`＝两种理解导致完全不同的实现，做错要推倒重来；`建议`＝局部偏差，需要返工一轮；`观察`＝措辞瑕疵，实现者大概率猜对，但不该留。拿不准就往 `建议` 放，别升 `阻断`。

## 一条 finding 要写全字段

```yaml
      - id: SS-001-01                  # 新增时在 SS-0nn 内递增铸造、不重号、不重用；删除或合并后允许号段空缺，绝不重编号
        type: <八类之一>
        where: <相对路径>:<行号>        # 原文所在位置；跨多处时写最主要那处
        quote: <原文摘录>               # 逐字，机器锚点不翻译；长句截关键片段
        read_as: <我读到什么>           # 一句话：这句话在当前语境下的含义
        stuck: <我卡在哪>               # 一句话：要做什么决策，为什么定不了
        would_guess: <我会猜成什么>     # 命根子：没人管的话我照哪种理解干
        impact: <猜错的后果>            # 一句话：猜偏了会怎样
        suggestion: <建议怎么裁定>      # 一句话：补什么能消歧（可选但强烈建议）
        severity: 阻断|建议|观察
        source: [穷举]                  # 本步产出固定标 [穷举]；数组可并存多值
```

## 去重：同一处只报一条

- 铸号前拿 `where` / `quote` 对已有 findings 核对：同一处已报（预演的 `[卡点]` 或本步前批的 `[穷举]`）→ **不新建条目**，把 `穷举` **并集追加**进原条目的 `source`（成 `[卡点, 穷举]`），本视角有新信息就往 `stuck` 补一句「另见 <位置>」。
- 合并后仍是一条；删除 / 合并留下的号段空缺不回收、不重排，绝不重编号。

## 写回（单写者）

- `{output_dir}/spec-scan.yaml` 同一时刻只有一个写者，**不引入分片文件**（不新开写面）。目标被外层并行分工时，本步**不写文件**——把 findings 条目（十个字段，**不带 `id`**）与单元名回给调度者，由调度者在单点写回时按批次顺序统一铸号（在该 `SS-0nn` 内递增、不重号、不重用）并改 `scanned` / `summary`。
- 直接写回时：每批穷举完，findings 追加写回、重算 `summary` 计数（`total` / `blocker` / `major` / `minor` 与 findings 一致），再开下一批。
- **单元标记接管**：本步穷举完一个单元，把仍为 `false` 的 `scanned` 改 `true` 并同步 `units_scanned`。若预演步（02）未执行——纯文档路由会跳过预演——`units[].scanned` 标记与单元计数**由本步接管**；02 已执行时标记已全为 `true`，本步不改。

## 播报与下一步

给用户一句话：枚举了多少条路径、新增几条（或零命中）、合并几条、余下 blocker 几条。

读全并照做 `./04-cross-check.md`。
