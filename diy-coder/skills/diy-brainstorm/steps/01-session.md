# Step 1 — 会话设置与续接（Session）

Progress: `[会话设置与续接] → 技术选取 → 教练执行 → 组织 → 收尾`

**Read (input):** 激活段 `list` 回执（会话清单，只含五字段）；用户对续接菜单与议题询问的回答。
**Write (output):** `{output_dir}/brainstorm.yaml` 的新记录骨架（经 `init` 铸造）或既有记录的状态推进；给用户的播报。

## 续接检测

激活段已跑 `list`——回执只给 `id` / `topic` / `date` / `status` / `current_step` 五字段，**到此为止，不许读正文**（源纪律：列名不读内容，选出目标才加载）。

- 回执 `sessions` 为空 → 直接进「新建会话」。
- 有记录 → 播报最近一条（`id` / `topic` / `date` / `status` / `current_step`），给菜单 **[1] 继续 / [2] 新建 / [3] 看全部**，**HALT 等选择**。
  - `[3] 看全部` → 列全部记录（仍只五字段）→ 问「继续哪一条（给 `id`）还是新建」。
  - `[2] 新建` → 进「新建会话」。

## 继续一条既有记录

先按 `id` 加载那一条记录（此时才读内容），播报进度：用过的技术、想法计数（`ideas` 条数）、当前阶段；**不重复已做过的提问**（源 01b 纪律）。然后按 `current_step` 复位到对应步：

| `current_step` | 去向 |
| --- | --- |
| 1 | 留在本步：补齐议题 / 目标，再走四选一 |
| 2 | 读 `./02-techniques.md`（技术还没选完） |
| 3 | 读 `./03-facilitate.md`（接着教练） |
| 4 | 读 `./04-organize.md`（接着组织） |
| 5（或 `status: 已完成`） | **只读回看**：展示 `themes` / `priorities` / `actions` 摘要即结束，**不再写入**；还想再发散 → 走「新建会话」铸下一条 `BS-###` |

续接时不重铸 `id`、不动 `date`。

## 新建会话（硬门）

1. 问两个问题（源 01 第 3.C 节）：**① 这次要发散什么议题？② 想要什么样的产出？**
2. **硬门（零产出退出）**：拒答 → 一行说明并停止，不写任何文件；「无议题也无素材」→ 同样拒绝，建议先想清楚要解决什么（**不代拟议题**，可路由 `diy-prfaq` 做点火）。
3. 复述确认（议题 + 目标各一句）→ 用户点头后调引擎铸骨架：

```
python "{project-root}/.claude/skills/diy-brainstorm/scripts/brainstorm.py" init --topic "<议题>" --goals "<目标>" --project-root "{project-root}" --output-dir "{output_dir}" --json
```

回执的 `id` 就是本条会话的 `BS-###`（本记录此后的一切写入都用它定位）。若有可读的会话上下文素材（`project-context.yaml`，或用户点名的 `prfaq.yaml` / `brief.yaml`），此时**只读**取用、以引用式提及（`path:<relative>`），禁复制内容。

## 四选一技术选取方式

问用户选哪种（源 01 第 3.E 节，语义逐条保留）：

```
[1] 用户自选技术 —— 逛完整技术库（61 技术 / 10 类）
[2] AI 推荐技术 —— 按你的目标定制推荐（每个给理由）
[3] 随机选技术 —— 撞出意外的创意方法
[4] 渐进式旅程 —— 先宽后窄，系统推进（探索→连接→深化→收敛）
```

选完把结果写进记录：`approach` 取 `用户自选` / `AI 推荐` / `随机` / `渐进流`（逐字），`status: 进行中`、`current_step: 2`。**这一步是 `approach` 的唯一写入口**——`current_step` 到 2 以上而没有 `approach` 会被终门判违规。

## 播报与下一步

一句话播报：新建（`BS-###` 已铸、议题与目标）或续接（回到哪一步、既有进度）；然后

读全并照做 `./02-techniques.md`。
