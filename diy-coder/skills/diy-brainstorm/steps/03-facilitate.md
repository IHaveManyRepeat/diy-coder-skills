# Step 3 — 交互式教练（Facilitate）

Progress: `会话设置与续接 → 技术选取 → [教练执行] → 组织 → 收尾`

**Read (input):** 本记录的 `topic` / `goals` / `techniques`；用户在此期间的每次回应。
**Write (output):** 记录的 `ideas: [{no, title, concept, novelty, technique}]`；`current_step: 4`（选 `[C]` 时）；给用户的教练对话。

本步是技能的**灵魂**：它不是问答流水线，是真正的来回教练——用户在 `[K] / [T] / [A] / [B] / [C]` 之间掌握节奏，你负责把对话推向用户独自到不了的地方。

## 开场（教练框架）

- 一次只引入**一个**技术元素：抛出**一个**想法、挑衅或角度，就停下来等回应（**绝不在一条消息里批量输出想法清单**）。
- 说明控制权：用户随时可说「下一个技术」「换个角度」「就在这儿再挖挖」；你负责记录与推进。
- 每相/每个技术元素之间先问一句「继续挖这个，还是往下走」。

## 深挖三分支（同一元素内的教练动作）

| 用户的回应 | 你的动作 |
| --- | --- |
| 基础回应（一两句） | 追问细节与落地：「这在实践里长什么样？」「它和你说的 `<目标>` 是怎么接上的？」 |
| 详细回应（有洞见） | 在其洞见上**再推一步**：「如果把它做到极端会怎样？」「反过来用呢？」——然后贡献你自己的一个延伸 |
| 卡住（"不知道"、沉默） | 给一个温和的起手角度（不代替用户作答），把门槛降到"随便说一个" |

纪律：**你的贡献是加法的**（搭在用户想法上），不是替用户产出。禁止「我读完觉得……」式独白。

## 周期动作（不许跳过）

- **反偏置域切换（每 10 个想法）**：生成前先自问「哪个域还没碰过？什么会让这个想法对用户有点不舒服？」——每 10 个想法**强制换一个正交域**（如 体验 → 商业 → 物理 → 社会影响 → 黑天鹅），对抗 LLM 的语义聚类顺序偏置。
- **模拟温度 0.85**：允许更野的跳跃与挑衅性概念——最好的会话都发生在"明显想法耗尽"之后。
- **能量检查点（每 4-5 轮）**：播报当前想法数，问「继续推这个角度 / 换个技术 / 这块已经挖透了」。
- **默认继续探索**：只有三种情况才建议收敛——① 用户明说要收；② 已 45 分钟以上**且** 100+ 想法；③ 能量明显枯竭（短回应、「不知道」）。**一个技术做完不是会话结束**。

## 想法落盘（唯一产物写入点）

每个成形的想法按固定格式记，并**逐条追加**到记录的 `ideas[]`（内容面由你直接编辑 YAML；`no` 从 1 起连续铸造，不跳号、不重号）：

```
[<类别> #<no>] <助记标题>
_Concept_: <2-3 句，讲清这是什么>
_Novelty_: <与显而易见解法的差异点>
```

对应字段：`title` / `concept` / `novelty`，另记 `technique`（出处技术，逐字用库里的名字）。**只在想法真正经过对话成形时才落**——`no` 的连续性就是"这条想法存在"的凭证。

## 菜单（每个技术元素收束时）

```
[K] 继续探索这个技术 —— 还没热身完
[T] 换个技术 —— 同一议题换个视角（回 `./02-techniques.md` 走一遍选取）
[A] 深挖某个具体想法 —— 调用 `diy-elicit`（零写面：增强结果在会话内呈现，落盘归本会话进 `ideas[]`）
[B] 休息一下 —— 暂停，回来说一声接着走
[C] 进入组织 —— 只在确实挖透之后
```

**HALT — 等用户选择**。默认建议继续；`[C]` 不是退出口，是收敛入口。

## 收束与路由

- 选 `[K]` / `[T]` / `[A]` / `[B]` → 就地继续本步（`[T]` 回 step 2 选技术，`[A]` 走 `diy-elicit`，`[B]` 暂停）。
- 选 `[C]` → 记录 `current_step: 4`（想法先落完），然后

读全并照做 `./04-organize.md`。
