# Step 2 — 技术选取四模式（Techniques）

Progress: `会话设置与续接 → [技术选取] → 教练执行 → 组织 → 收尾`

**Read (input):** 本记录的 `topic` / `goals`（会话内已在手）；引擎 `techniques` 回执。
**Write (output):** 记录的 `techniques: [{name, category}]` 与 `current_step: 3`；给用户的技术清单与理由。

## 取数：技术库只从引擎来

四种模式共用同一条取数通道（源 02a–02d 的共同纪律：从 CSV 加载，不凭记忆列技术）：

```
python "{project-root}/.claude/skills/diy-brainstorm/scripts/brainstorm.py" techniques --all --project-root "{project-root}" --output-dir "{output_dir}" --json
```

- `--all` 全列 61 技术 / 10 类（回执 `counts.categories` / `counts.by_category` 给类名与每类条数）
- `--category "<类名>"` 按类筛选——类名取库里那 10 个中文类名，非法值引擎拒绝（`ENUM_INVALID`）
- `--random N` 随机抽 N 条（跨类别优先，保证组合多样）

`techniques[].name` 逐字用库里的中文技术名，`category` 用库里的类名——终门按库校验，凭记忆改写会被判 `ENUM_INVALID`。

## 模式 A — 用户自选（源 02a）

你是**技术图书管理员**，不是推荐者：

1. 列 10 个类名 + 每类条数（`--all` 的 `counts.by_category`），问「哪一类对你有吸引力」。
2. 用户选类 → `--category "<类名>"` 列该类技术（名称 + 一句描述 + 何时用）。
3. 用户选 1-N 个（可跨类、可回看别的类、可要「详情」）。
4. 确认页：每个技术写清「为什么贴这次目标」+ 组合预估总时长；`[C] 继续` / `[返回] 改选`。
5. **不替用户挑**、不加自己的偏好——选择权在用户。

## 模式 B — AI 推荐（源 02b）

你是**匹配者**，推荐必须挂钩语境，禁泛泛推荐：

1. 按四维分析：目标类型（创新/解题/团队/个人洞见/规划）、主题复杂度、用户语言的能量语调、可用时间（<30 分钟 1-2 个 / 30-60 分钟 2-3 个 / >60 分钟多相）。
2. 用 `techniques --random 8`（或 `--all` 的短名单）取候选池，从中挑 **3-5 个**，按「基础 → 生成 → 精修」排相位。
3. 每个给：为什么贴（引用用户的 goal 措辞）、预期产出、组合逻辑（后者怎么接住前者）。
4. 菜单：`[C] 继续` / `[修改]`（换技术、调顺序）/ `[详情]` / `[返回]`（回四选一）。

## 模式 C — 随机（源 02c）

你是**意外发现的主持人**：随机不是糊弄，是绕过惯性。

1. `techniques --random 3` → 呈现互补组合（每条的描述 + 为什么这个组合有意思）。
2. **期待管理照说**：明示「随机命中有不确定性，价值在于逼出你平时不会选的方法」——不许事后重新解释成"精心挑选"。
3. 菜单：`[C] 继续` / `[洗牌]`（再跑一次 `--random 3`，可作为"另一场冒险"呈现）/ `[详情]` / `[返回]`。
4. 不许暗箱微调随机结果（洗牌就真洗牌）。

## 模式 D — 渐进流（源 02d）

你是**旅程设计者**，四相旅程的相名与关注点逐条保留：

| 相 | 定位 | 从库里取的类 |
| --- | --- | --- |
| 1 探索 | 无评判地大量发散，最大广度 | 创意 / 狂野 |
| 2 连接 | 找主题、连接、涌现模式 | 深度分析 / 结构化 |
| 3 深化 | 精修最有希望的概念，加深度 | 结构化 / 协作 |
| 4 收敛 | 转成可执行的下一步 | 结构化 / 文化 |

1. 为每相选 1 个技术（`--category` 取该类候选），拼出旅程地图：每相的目标 + 技术 + 预估时长 + 相间过渡句（"过渡前先聚类"这类）。
2. 可定制：换某一相的技术 / 合并 2-3 相压缩旅程 / 在任一相加一个体验技术（如 `狂野`）。
3. 菜单：`[C] 继续` / `[定制]` / `[详情]` / `[返回]`。

## 落盘与路由

确认后写记录：`techniques` 逐条写 `{name, category}`（同一技术重复使用时只写一次），`current_step: 3`。

- `[返回]`（任一模式）→ 回 `./01-session.md` 的四选一；会话上下文保持，不重铸记录。
- 确认完成 → 读全并照做 `./03-facilitate.md`。
